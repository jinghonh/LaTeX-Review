# LaTeX Review

## 选择任务

只读取当前任务对应的参考文件。

- 用户要求审阅论文修改或生成差异报告：读取 [审阅](references/review.md)。
- 用户要求当前论文持续预览、保存后自动刷新或不比较版本：读取 [持续预览](references/live.md)。此分支优先于差异审阅。
- 用户要求翻译报告变更：读取 [翻译](references/translation.md)。优先复用已有报告，默认报告保持原文。
- 用户要求添加、回复、编辑、删除或解决批注：读取 [批注](references/annotations.md)。只操作已有报告。

普通论文改稿完成后，检查用户指定范围和 Git 差异。用户要求审阅报告时才生成报告。用户要求页面验收，或任务涉及报告界面时，才执行浏览器验收。翻译任务按翻译参考检查对应页面。

## 共用规则

1. 确认入口、项目根目录、操作范围和需要的版本基线。保留用户已有修改。
2. 检查所需命令是否可用。参数以该命令的 `--help` 为准。缺少工具时说明安装方式，由用户决定安装。
3. 使用不含用户文件的专用输出目录。报告生成会替换所选报告目录。
4. 读取本次退出码、实际产物和诊断。旧文件、退出码或命令成功不能代替内容核对。
5. 启动服务时，保存进程或终端会话标识，并使用标准输出中的实际地址。
6. 用户要求持续预览时保留服务。其他任务结束或中断后，停止本次服务并确认退出。
7. 交付有效文件的完整路径，说明结果、限制及实际检查范围。服务停止后说明临时地址失效。

## 关键约束

- 审阅与翻译不回写论文源码。整篇编译仅在用户明确要求时启用。
- API 翻译遵守用户授权范围和已有的数据外发限制。配置与聊天只使用密钥环境变量名。
- 批量翻译不受页面筛选限制。只有用户要求整份报告时才使用。
- 批注原文重复时，用源码位置和上下文确定目标。换版后重新读取定位信息。
- 写入冲突后重新读取对象。已成功提交的批注操作只核对结果，不重复提交。
- 浏览器工具受限时，说明未完成的检查，并遵守访问限制。
- HTML 是内容预览。PDF 排版、在线公式依赖和复杂结构限制见对应参考。
