# 票据拆分决策

日期：2026-09-29。来源：技术设计文档及本轮访谈。本文件记录对原设计的范围澄清；初次创建39张票据后，用户要求第一版由22张压缩为9张；随后第一点五版由10张压缩为4张，第二版由6张压缩为3张；现保留16张实施主票与1张总览，22张旧票按已替代关闭；完整范围见[实施票据清单](latex-review-ticket-plan.md)，远程入口见[票据索引](latex-review-ticket-index.md)。

## 已确定

- 全部路线保留。第一版按用户指定的9组能力整合，细粒度内容作为票内工作清单与验收条件；第一点五版合为4张、第二版合为3张，原有范围与全部验收条目保留，由总览票组织依赖。
- 本轮明确影响范围和验收的关键决策；具体实现算法和依赖版本由实现任务验证。
- 第一版：五类基础差异、多文件源码定位、三栏点击跳转、筛选、基础诊断及代理调用协议。
- 第一版正式支持 macOS；其他操作系统不作为首版交付承诺。
- 第一点五版：缓存、同步滚动、键盘导航、上下文折叠、高级差异及报告单文件打包。
- 第二版：显式真实编译、页面视觉对比、沙箱渲染、持续集成自动发布及论文规则检查。
- 第一版允许联网加载公式渲染依赖，交付报告目录；不承诺完全离线或真正的单文件。
- 总变更数按主变更去重；引用等作为所属主变更的明细。分类命中数可重叠。
- 工作区版本采用磁盘当前内容，包含暂存及未暂存修改；纳入入口实际依赖、未被忽略的未跟踪文件。不提供仅暂存区模式，缺失依赖明确诊断。
- 源码定位验收以明确的指定样例为准，暂不使用原设计的95%指标。
- 第一版表格只做整体差异；单元格对齐及图片同路径内容检测后移。
- 完整报告返回0；可生成的降级报告（含结构解析整体失败后的源码对比）返回2；任一比较版本无法读取返回4；内部错误返回8。一般提示不改变成功状态。

- 第一版提供注释审阅开关：默认忽略注释；启用时注释变化独立分类并计入主变更总数，但不计正文增删词数。
- 始终生成独立诊断文件。联网公式依赖失败时显示原始公式与提示；生成阶段已发现的失败返回2，报告打开后的网络失败只更新页面状态。
- 第一点五版单文件报告仍允许联网加载公式依赖，不承诺完全离线；报告数据和本地展示资源须内嵌。
- 第一点五版提供受控的声明式宏占位配置；替代公式渲染器和辅助源码差异工具保留为技术备选，不单列实现承诺。
- 参考文献只展示作者、题目及年份等元数据；引用键不变的条目内容变化暂不生成独立语义变更，并明确提示该边界。
- 第二版显式编译默认处理旧新两个隔离副本，可选择只编译新版本；原工作区不变，默认禁用外部命令执行。
- 持续集成发布仅支持 GitHub，用户显式启用后上传产物并发布或更新同一条拉取请求评论；分叉请求默认只生成产物，无写权限则跳过评论并提示。
- 规则检查仅输出分级诊断，不改变退出码；区分已存在、新引入及已解决的问题。
- 最终验收必须使用用户指定的真实论文；模块测试仍可用合成样例，记录性能但不设百分比或硬性耗时门槛。

- 合票后的完成边界以整张主票为准：文献与宏兼容均完成后才解除规则检查阻塞；编译、视觉对比及沙箱均完成后才解除规则检查的另一项阻塞。票内子项可按依赖先后实现，但不能以部分完成关闭整票。
