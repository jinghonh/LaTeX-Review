# 变更内容翻译

报告支持点击后把变更内容译为简体中文，用于论文审阅中的辅助阅读。翻译经本机预览服务调用用户配置的兼容 OpenAI 文本对话接口；生成报告、直接打开静态报告和启动服务都不会自动调用模型。

## 配置与启动

在论文项目的 `.latex-review.toml` 中加入以下配置。地址和模型是示例占位值，需要替换成实际服务的设置。

```toml
[translation]
base_url = "https://api.example.com/v1"
model = "你的模型名称"
api_key_env = "LLM_API_KEY"
concurrency = 8
timeout = 60
max_retries = 2

[translation.glossary]
"operator" = "算子"
"reachable set" = "可达集"
```

`base_url` 可以是 API 基础地址，也可以是完整的 `/chat/completions` 地址。基础地址会追加 `/chat/completions`；服务必须接受 `model`、`messages`、`stream = false`，并返回 `choices[0].message.content` 文本。翻译结果由提示词要求为带原句编号的 JSON，不要求服务额外支持结构化输出参数。接口格式依据 [OpenAI 官方文本对话接口文档](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create)。具体服务的模型能力、价格和限额由该服务决定。

密钥仅从环境变量读取，配置文件不接受 `api_key` 字段。在 macOS 的默认 zsh 中，可以交互输入密钥后启动：

```sh
read -rs "LLM_API_KEY?请输入 API 密钥："
export LLM_API_KEY
latex-review main.tex
latex-review-preview .latex-review/latest --config .latex-review.toml
```

打开服务输出的 `http://127.0.0.1:端口/report.html`。预览命令默认读取启动目录的 `.latex-review.toml`；从其他目录启动时，使用 `--config` 指定论文项目配置。已有旧报告缺少翻译清单时，先重新生成一次报告。

可选的 `[translation].instructions` 字符串会追加学术翻译规则。`concurrency` 范围为 1–32，`timeout` 为 1–600 秒，`max_retries` 为 0–5；类型无效或未知字段会报配置错误。更改设置后重新启动预览服务。

## 阅读与操作

- **翻译此处**：变更目录和正文页边对照均提供按钮，处理该项修改前后两侧的内容。
- **翻译全部变更**：处理整份报告的翻译候选，不受当前目录筛选影响。默认最多 8 个请求同时进行，逐项显示完成、失败或等待状态。
- **英文原文／英中对照**：切换译文展示，保持原文可核对。翻译只提供阅读结果，不生成或回写中文论文源码。
- **停止翻译**：停止尚未发送的请求及后续重试。已经发送的请求可能继续完成并产生费用，成功结果仍保留。
- **导出含译文报告**：下载带已有译文和受管阅读资源的单文件报告。导出后可直接打开；公式排版沿用原报告的在线依赖。继续请求新的翻译需要原报告目录和本机服务。

翻译范围是**包含变化的完整段落**，而不是整篇论文。如果一个五句的段落只改了第二句，修改前后两个完整段落都会翻译，中文只有对应第二句的位置带变更标记。新增或删除段落只处理存在的一侧；发生变化的标题和图注翻译完整文字。没有变化的段落、表格、独立公式、参考文献条目和源码注释不进入本轮翻译。

模型在整段上下文中逐句返回结果。公式、引用、数值和常用文字格式先替换为占位符，再校验顺序和完整性并恢复；缺句、错位或结构被修改时该项显示失败。中文句子沿用英文判定的变更范围，翻译不重新计算差异、词数、源码位置或主变更数。语义忠实程度仍需阅读原文核对，不作为正式中文稿质量保证。

## 缓存与失败

翻译候选保存在报告目录的 `translation-units.json`；它只包含选定阅读内容的净化文本和安全预览片段。翻译缓存默认位于报告目录同级的 `translation-cache/`，可用预览命令的 `--translation-cache-dir` 指定独立目录。该缓存与结构解析缓存分开，重新生成报告后可以继续复用。

缓存依据段落内容、保护结构、接口地址、模型、目标语言、翻译规则版本、附加规则和术语表建立内容指纹。变更标记和页面位置在当前报告中重新关联，相同内容无需再次请求。失败结果不保存为成功缓存；损坏或不兼容缓存会重新翻译。修改并发或超时不使成功译文失效。

默认单次请求超时 60 秒。限流、连接失败及暂时的服务错误最多重试 2 次；配置错误、拒绝、不完整输出和无效 JSON 显示逐项失败，可再次点击重试。部分失败不影响成功译文或原报告阅读。服务错误信息不包含远端响应正文或密钥。

密钥只在本机服务调用配置地址时使用。浏览器请求只提交报告内的内容标识，服务不接受任意外部文本；翻译接口验证当前本机来源和会话令牌。译文导出不包含密钥或服务会话令牌。预览期间保持报告目录稳定，结束后按 Ctrl+C 停止服务。
