# 缓存与图资源内容变化

命令行将每侧结构解析结果保存为校验过的 JSON。解析键包含入口、实际包含的 TeX 文件内容指纹、展开文本与来源映射、配置，以及解析器、渲染器和 plasTeX 版本。审阅键另包含图与文献资源内容指纹和依赖关系。每次运行都会重新展开当前来源并读取实际依赖；因此工作区的暂存、未暂存及未忽略文件变更会进入键。Git 固定提交的解析结果可以跨运行复用。缓存 JSON 校验或结构验证失败时重算；并发写入先写独立临时文件，再原子替换同一内容键。

缓存粒度目前为**单侧完整项目的结构解析**。章节或宏修改会使对应侧解析键失效，另一侧保留命中；图片或文献字节变化更新审阅键，但结构节点可以继续复用。整篇结构树依赖章节路径与全文宏状态，因此单章变化仍需重建该侧结构树。报告生成和双侧资源复制每次执行；缓存不会复用过期图片，也不会复用旧源码位置。`cache-meta.json` 记录两侧的 `state`（`miss`、`hit`、`corrupt`、`bypass`、`unavailable`）、解析键、审阅键、依赖指纹和依赖关系。缓存元信息与机器差异分开保存，冷热运行的 `diff.json` 可直接比较。

默认缓存位于报告目录旁的 `cache/`（默认报告为 `.latex-review/latest/`）；自定义报告目录旁使用 `.latex-review-cache/`。可用 `--cache-dir PATH` 显式选择，`--no-cache` 只绕过本次读写，`--clear-cache` 在本次运行前清理。清理拒绝覆盖来源根目录；显式指定在来源目录内部的缓存位置也拒绝清理，只有程序默认的受管位置允许此情形。清理前会校验缓存文件信封、键及校验和；中断写入遗留的新旧临时文件名也可清理。目录混有其他文件或符号链接时拒绝。缓存无法写入时使用本轮新解析结果并记录 `unavailable`；若来源在快照处理期间变得不可读，运行按来源错误退出。不会把缺失或损坏缓存当作成功解析。

图资源按两侧实际解析的依赖文件计算 SHA-256。匹配图节点中同一命令参数对应的两侧资源都有内容且指纹不同，添加“图资源内容变化”明细；路径改变仍保留资源路径明细。资源缺失保持来源与报告的缺失诊断，不写内容变化明细。每个引用共享资源的图都有可定位的明细，而总变更数仍按图主变更计。这是文件字节比较，不判断像素或视觉相似度。

## 性能记录

执行 `python scripts/benchmark-cache.py` 可在临时 Git 样例中重测。以下为 2026-09-29 的一次实测，设备 macOS 27.0、arm64、Python 3.13.2；样例有 12 个章节文件，每章 20 段，仅修改第 4 章。耗时含 Python 启动、Git 快照、比较、预览及报告写入；不同设备与样例不可直接比较，不设硬性门槛。

| 运行 | 耗时 | 旧侧缓存 | 新侧缓存 | 主变更 |
| --- | ---: | --- | --- | ---: |
| 冷运行 | 3.389 秒 | 未命中 | 未命中 | 1 |
| 热运行 | 2.923 秒 | 命中 | 命中 | 1 |
| 单章增量 | 2.757 秒 | 命中 | 未命中 | 2 |

冷、热运行的 `diff.json` 语义数据完全相同。单章增量与冷运行输入不同，主变更数增加 1。
