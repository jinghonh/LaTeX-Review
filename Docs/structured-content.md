# 结构化内容差异接口

主票 #10 在 `compare_projects(old, new)` 的 `ComparisonResult.document` 中提供公式、引用、图和表的主变更及明细；两侧仍由 `parse_project` 产生。`ReviewDocument` 沿用公共契约，`ChangeDetail.source_old` 和 `source_new` 是可选源码位置。引用及行内公式的明细保留各自的双侧位置；独立公式、图、表的主变更位置指向其整体节点。缺侧的位置省略，不用虚构坐标。

## 计数与分类

- 段内文字、引用、行内公式同时变化时只形成一个段落主变更；引用与公式站点先依据相邻正文和内容对齐，插入或删除不会挪用后续未变站点的来源。相同引用键不能越过不同正文位置强行配对；位置移动保留旧侧删除与新侧新增的各自来源。每个引用位置各有一条明细，键集合比较忽略同一位置的顺序和重复键。移除引用词元后相邻的普通空白边界会合并，纯引用变化不命中正文分类；保留引用或公式周围真正变化的空白仍作为正文明细。
- 独立公式形成公式主变更。规范化 TeX 词元忽略普通空白，并将 `\label`、`\tag`、`\notag`、`\nonumber` 作为编号元信息；数学内容与元信息分别出明细。解析不可靠时保留两侧公式原文并输出 `equation_diff_fallback`，其余变更继续处理。预览使用在线公式排版，失败时原始 TeX 仍可阅读。
- 图的资源路径、图注和标签分别出明细，同一图只计一个主变更。资源不存在时保留路径和图注差异，来源诊断为 `missing_dependency`，预览中显示缺失提示。**同一路径下图片内容是否变化暂不检测**，属于后续版本。
- 表格新增、删除和修改均以整个表格为一个主变更。`ChangeDetail.old_text` 和 `new_text` 保留完整 LaTeX；简单 `tabular`、`array` 与矩阵在双侧预览中生成阅读表格，单元格及可确定的行列变化由坐标明细标记。复杂宏、跨行跨列、嵌套或重复行歧义时整体回退并说明。数学环境内的数组与矩阵保留为公式下的表格节点及明细，归属公式主变更，仍只计一项。行列插入和多处修改仍只计一项主变更。

`build_summary` 的总数始终按主变更计，分类筛选取主变更类别与明细类别的并集；一个主变更可同时命中多个类别。旧新节点来源以及每个位置明细的来源均为所属版本的原始文件相对路径及坐标。结构化节点在同一父结构内数量相等、标签与内容锚点仍无法配对时，按剩余顺序建立置信度为 0.75 的配对；数量不等时保留新增和删除。高置信移动条件见[高级差异](advanced-diff.md)。

合成验收样例在 `tests/test_structured_diff.py`：行内、展示和对齐公式；标签与编号标记；重复引用键、位置重排；图路径、图注、标签和缺失资源；`tabular`、`array`、行列插入、合并单元格及嵌套宏。命令行尚未接入完整报告生成，后续报告层可直接消费此接口和 `render_preview`。
