# 论文规则诊断（#38）

`write_report` 在两侧结构解析成功后检查论文规则。结果同时写入 `diff.json`、`diagnostics.json` 和报告的诊断区。每条规则诊断保留原有的 `code`、`severity`、`message`、`source_old`、`source_new`，另有 `rule_status`（`existing`、`new`、`resolved`）、非空 `evidence`，以及列出全部命中位置的 `related_sources_old`、`related_sources_new`。两侧均有同一规则键为既有，仅新侧有为新增，仅旧侧有为已解决。位置按原始源文件映射；映射不确定时给出未知来源及理由。

| 代码 | 检查依据 | 级别 |
| --- | --- | --- |
| `bibliography_key_unresolved` | `\cite` 等已支持引用命令中的键在已读取 `.bib` 条目及手写 `\bibitem` 中均不存在 | 警告 |
| `unresolved_reference` | `\ref`、`\eqref`、`\autoref`、`\pageref` 的目标标签不存在 | 提示 |
| `duplicate_label` | 同一侧 `\label` 键定义超过一次；证据和关联位置列出每次定义 | 警告 |
| `figure_unreferenced`、`table_unreferenced` | 有唯一标签的图或表没有被上述交叉引用命令引用 | 提示 |
| `equation_number_changed` | 同一唯一标签的 `equation` 环境，两侧可靠编号不同；优先使用本次编译编号，其次使用字面值 `\tag{}` | 使用编译编号时为提示；仅比较显式编号时为警告 |
| `equation_number_unknown` | 同一标签的 `equation` 环境发生结构序位或章节变化，或仅一侧可读出编号；缺少双侧可靠编号 | 提示 |

扫描已展开的正文，忽略普通注释、常见逐字环境及行内 `\verb`、`\verb*`。只有文献引用命令按逗号拆分多个键；标签和交叉引用目标中的逗号属于键本身。正常删除引用不会产生“新增”问题；旧侧原有问题随引用删除会显示为“已解决”。手写 `\bibitem` 可证明引用键存在，即使其元数据仍无法结构化展示。只有两侧参考文献来源都可可靠读取时，才判断缺键问题为既有、新增或已解决；任一侧文件不可读、格式无法解析、文献资源缺失，或手写 `thebibliography` 环境内的 `\input`／`\include` 来源缺失时，不推断该规则的状态，保留相应来源诊断。没有唯一标签的图表不判定“未被引用”；重复标签由专门规则报告。未知宏、自定义引用命令、动态生成的键及复杂数学环境不参与确定性判定。

公式编号规则优先读取本次编译产生的 `compiled/<side>/numbering.json`。两侧证据分别标明编译编号或显式编号。实际编号相同时，即使结构序位改变也不产生编号诊断。自动编号变化属于一般提示，不表示论文错误。缺少编译编号时，规则只接受明确的字面 `\tag{}`；不会把预览的计数器估计当作最终编号，也不会单独读取工作区 `.aux`。

规则诊断仅供审阅，不构成发布阻断条件，也不单独改变命令退出码。来源读取、结构解析、报告资源或真实编译降级仍沿用原有退出码协议。结构解析整体失败时生成源码对比报告，规则检查不在缺乏可信结构的报告上运行。
