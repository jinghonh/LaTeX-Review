# 表格、移动与公式高级差异

`compare_projects` 仍按独立审阅结构输出主变更。表格中多处单元格变化、移动后的正文修改及公式结构摘要都是所属主变更的明细，分类命中可重叠。

## 表格

简单 `tabular`、`array` 与 `matrix`、`pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix` 使用同一保守扫描器进行差异和预览。扫描器识别顶层 `&` 与 `\\`，跳过花括号、行内数学、引用参数和转义分隔符。结构不变时按坐标比较单元格；插删行列时先用唯一完整行列锚定，再在唯一高相似候选下对齐剩余项。明细的行列坐标从 1 开始，报告点击明细时标亮对应侧单元格、整行或整列。

跨行跨列、嵌套环境、未知复杂宏、重复行或空单元格造成歧义时，保留表格整体原文与回退理由。此机制只定位文本单元格，不解析任意宏或证明单元格内数学等价。

## 移动

同章节重排先以一对一节点匹配和唯一最长保序锚点判断移动；移动节点本身还需唯一标签或全局唯一的完整内容。跨章节只接受全局唯一的显式标签加足够的正文连续性，或全局唯一且完整相同的内容。仅有相似文本不会推定移动。无法唯一判定的重排按删除和新增保守呈现。`moved` 主变更属于 `move` 类别，保留旧新章节路径、双侧源码位置；局部修改仍作为同一主变更的其他类别明细。

## 公式

在基础 TeX 词元差异上，受限结构解析支持变量与常量、上下标、分式、根式、函数参数和常见二元运算。摘要描述结构位置的替换或子表达式增删，不断言数学等价。含未支持宏或环境时，回退基础词元摘要；词元也无法可靠解析时保留双侧完整原文和诊断。公式预览始终使用原有原文路径。
