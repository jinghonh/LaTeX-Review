# 固定入口地址栏修复

日期：2026-10-13。问题：CLI输出固定论文链接，但浏览器随后显示随机工作端口。
原入口对论文链接返回302，浏览器按Location导航到工作进程。原浏览器测试还断言此跳转。

## 修复

入口返回200及全屏iframe页面，浏览器地址栏保持 `/papers/{paper_id}/{live,diff}`。
报告在原工作origin内运行，根API、资源、翻译、批注和导出保留原行为。
入口CSP仅允许当前工作origin作为frame源；iframe不获得入口控制令牌。
入口页面检查服务代次，工作进程替换后重新加载同一固定地址。
报告停用后，该固定地址显示管理页面。
纯上传和静态报告生成不调用这个显示页面。

## 验证

浏览器回归先复现地址从入口端口变成工作端口，再验证固定地址和真实报告内容。
同一测试还验证报告替换后自动加载新代次，地址不变，工作API仍在工作origin。
两类报告的搜索、批注、导出、监听刷新及翻译测试保留原功能断言。
HTTP测试先检查入口返回200且没有跳转，再从iframe读取实际报告和根API。
