## 交付范围

## 前置依赖

无。


## 内部工作清单与验收条件

### 原任务01：建立可安装的命令行工程与验证入口

在 macOS 上安装项目后可调用 latex-review，工程具备运行后续能力测试的统一入口。

#### 验收条件

- [ ] 声明并验证支持的 Python 版本、安装方式与依赖；干净环境安装后帮助命令可用。
- [ ] 建立包结构、测试入口和 macOS 自动验证流程，帮助文字及错误输出使用统一约定。
- [ ] 快速开始说明清楚标识尚未实现的能力，帮助命令不会触发论文编译。

#### 范围边界

首版正式支持 macOS；不承诺 Linux 或 Windows，也不在本子项实现完整审阅流水线。


### 原任务02：定义审阅节点、主变更与诊断的数据契约

各模块及报告共用可验证的数据模型，机器接口能够稳定表达主变更及其明细。

#### 验收条件

- [ ] 定义带版本号的节点、变更、来源、摘要及诊断模式；保留原文、节点层次和旧新位置。
- [ ] 分别表达匹配置信度与源码定位置信度；无法确定的位置可为空并附理由，不伪造精确行号。
- [ ] 总数按主变更计数，内嵌引用和公式等明细可被分类筛选；分类命中数允许重叠。
- [ ] 新增与删除允许一侧节点及位置为空；序列化顺序确定，提供模式校验与代表性快照。
- [ ] 记录兼容性规则：新增可选字段保持兼容，改变既有字段语义须显式升级格式版本。

#### 范围边界

领域词汇以 CONTEXT.md 为准；本子项定义契约，不代替后续各类差异实现。


## 设计依据与计数口径

[原始技术设计](https://github.com/jinghonh/LaTeX-Review/blob/a148d6cf96472d7936e618b19e7290acec9d30a2/Docs/latex-review-technical-design.md)，对应章节：12、13、16；4、7.7、9、14。

## 内部工作清单与验收条件

### 原任务03：隔离读取两个项目目录及独立源文件

无需 Git，也能为两个目录或独立文件建立互不混用的比较来源。

#### 验收条件

- [ ] 支持 --old-dir、--new-dir、--entry 及两个独立源文件的输入形式，明确互斥参数。
- [ ] 每侧依赖只从各自项目根解析；独立文件模式以各自父目录为根并沿用依赖解析规则。
- [ ] 校验入口存在、可读及位于允许根目录内；无效来源提供结构化错误。
- [ ] 用同名但内容不同的双侧依赖样例证明不串读，且原文件不会被修改。

#### 范围边界

递归依赖由本主票的项目展开子项实现；目录越界和链接逃逸的统一防护由安全票补齐。


### 原任务04：递归收集和展开论文项目依赖

入口与包含文件、图资源、参考文献构成可追踪的完整项目。

#### 验收条件

- [ ] 递归处理 input/include、相对路径和省略扩展名，收集常见图及参考文献依赖。
- [ ] 检测直接和间接包含循环；区分合法重复包含与循环，诊断附包含链。
- [ ] 保留每段展开文本的来源与包含实例标识，宏定义和调用内容不能在展开中静默丢失。
- [ ] 提供嵌套目录、重复包含、缺依赖和循环样例；一个节点跨多个文件时保留全部来源。

#### 范围边界

不实现通用 TeX 宏执行；无法静态确定的依赖明确诊断。


### 原任务05：把审阅内容映射回原始源码位置

报告能定位到各比较版本的原文件，且不可靠定位始终可辨认。

#### 验收条件

- [ ] 建立展开范围到原文件行列及字符跨度的映射，明确偏移单位、行号基准和区间端点约定。
- [ ] 覆盖多字节文本、不同换行、嵌套及重复包含；多来源节点不得伪装成单个连续原文范围。
- [ ] 普通确定样例与人工标注的文件及行范围逐项一致；无法精确映射的样例输出近似或未知标识。
- [ ] 原始位置与展开位置分开表示，旧新两侧的映射独立。

#### 范围边界

以明确样例验收，不沿用原设计95%的统计目标。


### 原任务16：比较完整 Git 版本和工作区快照

默认正确比较 HEAD 与磁盘工作区，历史项目不会偷读当前依赖。

#### 验收条件

- [ ] 支持指定两个提交；完整物化各版本入口、包含文件和资源，固定记录实际提交标识。
- [ ] 工作区取磁盘当前内容，纳入暂存及未暂存修改，以及入口依赖且未被忽略的未跟踪文件。
- [ ] 验证已暂存后再次修改、文件删除、新增依赖、被忽略的未跟踪依赖及同名历史资源；缺依赖给出诊断。
- [ ] 无 Git 或无有效 HEAD 时明确提示显式来源；不修改索引、分支或工作区，临时副本正常及异常均清理。

#### 范围边界

不提供仅暂存区比较模式；不自动拉取远程或初始化外部子模块。

- [ ] 未知内容可见、原文可查；页面明确标识内容预览，不能暗示等同最终版式。

#### 范围边界

## 内部工作清单与验收条件

### 原任务07：稳定匹配两版论文节点

插入或删除段落后，未变化内容仍能正确配对。

#### 验收条件

- [ ] 结合标签、章节、类型、规范化内容及邻域匹配，并输出可复用的双侧映射。
- [ ] 段落插入、标题编号变化、重复正文、标签重复及大量修改均有专门样例。
- [ ] 歧义或低置信匹配采用删除与新增，输出置信度与说明；不同节点类型不强行配对。
- [ ] 同一输入多次运行结果稳定，单节点不会被多次配对。

#### 范围边界

跨章节移动识别属于第一点五版。


### 原任务08：生成正文词语差异并抑制排版噪声

段落差异优先展示可读文字，同时保留语义敏感边界。

#### 验收条件

- [ ] 普通正文空白、换行和默认忽略的注释不制造语义变化；原始源码保持可查。
- [ ] 保护命令参数、引用、交叉引用、行内公式和逐字环境；语义空白不得被全局删除。
- [ ] 输出可显示的词元增删和确定的增删词数，文档说明中文等无空格文字的计数规则。
- [ ] 用纯空白修改、命令参数、逐字内容、英文及中文段落样例验证；内嵌变化按主变更规则聚合。

#### 范围边界

首版提供注释审阅开关：默认忽略；启用后注释独立分类并计入总变更，不计正文增删词数。需覆盖段内、独立行注释及转义百分号。

## 内部工作清单与验收条件

### 原任务09：比较公式内容与公式标签

公式修改能够分别查看两版正常数学表达，并按需查看符号变化。

#### 验收条件

- [ ] 覆盖行内、展示及对齐公式，输出规范化 TeX 词元摘要。
- [ ] 仅标签或编号标记变化时，作为元信息明细呈现，不谎报数学内容改变。
- [ ] 公式位于段落内时归属段落主变更；独立公式可形成独立主变更。
- [ ] 复杂或不支持的公式回退为两版原文，局部差异失败不破坏其余结果。

#### 范围边界

不要求公式抽象语法树，也不对复杂公式强制逐字符染色。


### 原任务10：识别引用键增删并避免重复统计

审阅者能看到某处新增及移除的引用，数据和页面遵守一致计数规则。

#### 验收条件

- [ ] 比较各引用位置的引用键集合；同一位置键顺序变化不算增删。
- [ ] 同一引用键在不同位置增删仍保留各自来源，不能用整篇全局集合掩盖变化。
- [ ] 段落引用变化归入段落明细，既修改文字又修改引用时只计一个主变更。
- [ ] 引用筛选可以命中这些明细；提供重复键、多处引用和键重排样例。

#### 范围边界

参考文献元数据展示与条目内容比较属于后续范围。


### 原任务11：比较图资源路径、图注和标签

图相关变化作为可定位的图主变更及明细展示。

#### 验收条件

- [ ] 分别识别资源路径替换、图注文字增删和标签变化。
- [ ] 同一图同时变化多个方面仍只形成一个主变更。
- [ ] 资源缺失时仍可生成路径与图注差异，并把缺图交给诊断与预览层呈现。
- [ ] 提供路径替换、仅图注、仅标签和多方面组合变化样例。

#### 范围边界

图片同路径下的内容检测明确推迟到第一点五版，首版帮助及报告须说明。


### 原任务12：提供表格整体差异与原文回退

表格变化可读、可定位，复杂表格也不会丢失原始内容。

#### 验收条件

- [ ] 识别表格整体新增、删除和修改，提供旧新表格及源码摘要。
- [ ] 处理常见 tabular/array 及含复杂宏的表格；不支持渲染时保留两版原文。
- [ ] 行列插入、合并单元格和嵌套宏样例均能生成整体差异。
- [ ] 表内多处修改只计表格主变更，不能声称已精确定位单元格。

#### 范围边界

首版不做单元格级差异；本口径覆盖原设计7.6中的首版尝试性要求。
