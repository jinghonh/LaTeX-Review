# 报告预览

使用独立命令预览任意已生成的报告目录，无需重新生成报告：

```sh
latex-review-preview .latex-review/latest
```

增加 `--open-browser` 可在服务启动后自动打开默认浏览器：

```sh
latex-review-preview .latex-review/latest --open-browser
latex-review main.tex --open-browser
```

`latex-review --open-browser` 先生成报告，再预览实际输出目录，并沿用 `--config`。报告含警告时也会启动预览；停止服务后保留审阅退出码。预览启动失败返回 4，已生成的报告保留。两个命令都交给常驻入口管理。启动成功后 CLI 返回，服务继续运行。
`--wait` 附着状态；Ctrl+C 只断开客户端。使用 `latex-review-local stop` 显式停止受管服务。浏览器无法自动打开时，服务继续运行，请手动打开输出地址。

也可以传入 `report.html`，或在生成报告时的工作目录中传入论文入口：

```sh
latex-review-preview .latex-review/latest/report.html
latex-review-preview neural_networks/main.tex
```

传入 `.tex` 时只打开已有报告，采用启动目录配置中的 `output`，未配置则使用 `.latex-review/latest`。`--config` 可以选择项目配置。若生成报告时使用了 `--output`，请直接传入对应的报告目录；预览不会重新生成报告。

更新安装项目后即可获得该入口。也可在已安装本项目的 Python 环境运行：

```sh
python -m latex_review.serve .latex-review/latest
```

命令校验目录内存在 `report.html`，仅监听 `127.0.0.1`，默认由系统分配空闲端口。标准输出给出稳定论文链接。启动提示写入标准错误；服务访问日志位于状态根的日志目录。可用 `--port 端口` 指定端口；端口冲突或报告无效时返回 4，参数错误返回 2。CLI 返回稳定论文链接，该链接在固定入口页面内显示当前报告，地址栏保持入口端口。工作端口可随替换改变，入口页面自动加载替换后的报告。
入口默认监听 `127.0.0.1:8765`；`--port` 指定差异工作进程端口，不指定入口端口。

服务提供完整报告目录，保留图片和预览的相对路径；关闭目录列表并拒绝解析到报告目录外的符号链接。差异服务读取完整受管副本。后续离线生成不会直接覆盖当前阅读副本。
相同报告请求复用服务；不同基线和参数按同一差异槽位串行更新。候选失败时保留旧报告。响应禁用缓存，以便重新加载后看到当前资源。单纯读取不改写原报告目录。批注源码建议会更新论文源码和受管副本。仅指定 `--open-browser` 时自动打开浏览器。

本机服务支持按需翻译。配置、缓存、导出和 `--translation-cache-dir` 用法见[翻译指南](translation.md)。

## 阅读与对照

报告默认展示完整新稿。宽屏时，对应段落右侧的页边卡片显示变更类型、编号和改动组数，随正文一起滚动；相邻卡片拥挤时向下排列。展开后优先逐组显示相邻的修改前后片段，仅保留少量上下文，删除词句使用删除线，新增词句使用高亮；公式和引用保留完整展示。同一句涉及多种类别时，主要对照只展示一次，补充明细保留在全文展开区。点击正文划线、页边卡片或删除位置的小标记，会定位并展开对应对照，同时高亮对应内容；每次只展开当前一张卡片。正文划线也可用键盘聚焦后按回车或空格激活。窄屏时卡片回到对应段落下方，保持相同操作；打印时也恢复为段落下方的对照。

每个改动组下的“本处中文译文”独立展开，仅显示该组对应完整句子的修改前后译文。“完整段落对照”和“整段中文译文”保留在卡片底部，分别按需展开。正文的原文／双语切换不改变右栏译文区域的展开状态；正文中的中文变更句仍可点击定位对应改动组。

整段删除保留原位置附近的查看入口，无法可靠定位时显示位置提示。变更目录默认收起，打开后可按操作和类别筛选；上一处、下一处及键盘快捷键会定位并展开对应改动。点击被当前筛选隐藏的正文划线，会恢复全部变更，使对应卡片可见。

工具栏可切换双稿对照，并启用同步滚动。报告说明、诊断及可用的编译页面默认折叠，页面链接会自动展开目标区域。界面只维护当前阅读位置，不保存已审阅进度。

章节、图、表、公式、章节目录及交叉引用显示一致的编号。启用 `--compile` 时，编号取自实际编译结果。
窗口或侧栏改变正文宽度时，预览保持可见文字及其相对视口位置。关闭同步滚动后，双稿各自保持阅读位置。

## 智能体验收

项目的 [LaTeX Review 技能](../.agents/skills/latex-review/SKILL.md) 默认要求启动预览、检查实际页面并清理进程。检查覆盖报告内容、截图中的排版及资源、筛选、折叠和页面内跳转；不存在的控件不计入检查。外部编辑器协议单独记录，HTTP 页面可用不代表外部协议可执行。

HTTP 服务正常与浏览器工具允许访问是两个独立条件。工具缺失或明确禁止访问本机地址时，继续核对机器数据，并报告渲染及交互验收未完成。不得把源码读取或普通 HTTP 请求成功当成浏览器验收成功，也不得规避工具的访问限制。MathJax 仍需联网；加载失败应记录页面的降级表现。

验收结束或中断后，显式停止本次创建的槽位并确认退出；不得停止此前已有的共享服务。交付报告文件路径和验收结果，已停止服务的临时地址不作为可用链接交付。

报告提供独立章节目录。桌面默认展开，窄屏通过“章节”按钮打开。目录默认显示两级标题，更深标题可展开；浏览器保存展开状态。章节目录与变更目录切换显示。

点击章节标题会定位章节开头；双稿对照同时定位对应标题。滚动正文时，目录高亮当前章节。旧稿独有章节保留在原位置并标注“已删除”，点击后打开双稿对照。

章节旁显示“变更总数 · 未审阅数”。父章节累计子章节的主变更，同一主变更只计一次；“待处理”不计入未审阅。没有变更的章节仍显示。

`latex-review-live main.tex --open-browser` 的持续预览也提供章节目录和滚动高亮。目录只展示当前论文标题，不显示变更计数。搜索使用独立入口。自动刷新保留目录开关、展开状态及原有阅读位置。

审阅报告和持续预览共用阅读工具。两种入口均可搜索原文、引用键和已有译文。搜索不包含批注及交互控件文字，也不重复计算父节点中的子节点文字。译文更新后，当前搜索结果会立即更新。

## 报告体积与资源共享

普通 `report.html` 使用本机服务读取正文清单和批注，不携带完整批注备份或 Base64 资源副本。请使用 `latex-review-preview` 打开。直接双击仍可阅读正文，但批注需要本机服务。

独立导出的 HTML 保留批注和内嵌资源，可离线读取、编辑批注。公式排版仍使用在线 MathJax。浏览器“导出最新 HTML”、命令生成的单文件报告和译文导出均保留此能力。

输出位于论文的 `.latex-review` 内时，资源按内容哈希存入 `resource-cache`。报告内使用硬链接，保持原有相对路径。无法创建硬链接时保留普通副本。生成器通过替换写入更新资源，不会改写其他报告共享的文件。请勿原地编辑报告资源或缓存文件。

## 持续预览的文件监听

`latex-review-live` 使用 `watchfiles` 的原生文件事件。macOS、Linux 和 Windows 使用同一监听接口。保存事件最多合并300毫秒；构建期间的后续保存会触发下一次构建。监听器在首次构建前启动。

监听范围覆盖项目根目录内的正文、包含文件、参考文献、图片、PDF和配置。新增、删除、重命名、原子替换和目录重建也会触发刷新。项目内符号链接的目标由原始项目路径监听；解析器仍拒绝项目根目录外的依赖。显式配置位于项目外时，监听器每秒检查该配置文件的元数据。翻译配置仍在服务启动时加载，修改翻译设置后需要重启服务。

监听器排除报告输出、翻译缓存、`.latex-review`、`.git`、虚拟环境和 Python 缓存。批注存储仍由批注接口更新，批注轮询不会重建正文。原生监听每30秒执行一次元数据核对，以补获未交付的事件。核对不读取文件内容，也不计算项目内容哈希。

监听器启动失败、运行失败或项目根目录被替换时，服务显示降级提示。服务随后每0.7秒执行一次元数据检查。每次检查所需时间另计。检查包含文件大小、纳秒时间和 inode，以检测原子保存和保留修改时间的替换。检查失败时，页面显示预览可能过期。回退持续到服务停止；重启服务会重新尝试原生监听。

对于网络盘、容器挂载或不能可靠交付文件事件的文件系统，请显式使用安全回退：

```sh
latex-review-live main.tex --poll-files
```

此回退减少内容读取，但大项目仍可能产生较高元数据检查成本。原生监听的安全核对最多延迟30秒发现丢失的事件。原生事件的正常更新不等待核对。此功能不保证发现同时保留 inode、大小、修改时间和状态变更时间的非标准文件系统写入。修改项目根目录、输出位置或翻译配置后，需要按相应启动参数重启服务。

### PDF 转换缓存

PDF 图片预览和编译页面栅格化现在复用同论文转换结果。报告位于 `.latex-review` 时，缓存存放在 `.latex-review/pdf-cache`。其他输出使用输出目录内的 `pdf-cache`。这些位置沿用实时监听排除范围。论文之间不共享转换缓存。

缓存键包含完整 PDF 字节的 SHA-256、页码、输出格式、灰度/缩放或 DPI、转换器路径、可执行文件内容、版本输出和转换实现版本。路径和修改时间不能代替 PDF 内容。当前未支持的裁剪、旋转和 pagebox 参数仍显示降级诊断，不读取另一组参数的预览。正文修改且 PDF 字节未变时复用预览。PDF 字节改变时重新转换。

缓存在同论文锁内生成结果。转换使用已计算哈希的 PDF 快照。完整输出通过格式检查后，以带 SHA-256 的单文件原子替换。损坏和部分结果重新生成。失败不替换有效缓存，也不改写已生成的报告资源。每次检查转换器版本有少量子进程成本；缓存不跳过 LaTeX 片段编译或 SyncTeX 定位。

缓存最多保留 512 个结果、128 MiB。30 天未使用的结果会在下次访问时清理。清理按最近使用时间执行。单次转换仍允许最多 12 MiB 临时结果。缓存清理只删除缓存，不删除报告图片、PDF 或正常报告。现有资源硬链接缓存独立管理。删除 `pdf-cache` 后，下次构建会重新转换。

报告内的资源 URL、页面配对、打印、发布和独立 HTML 的 PDF/图片内嵌规则保持原样。缓存不是交付资源，也不会上传。

### 长报告与公式调度

报告保留完整正文 DOM。搜索、浏览器查找、锚点、历史定位和文字选择不依赖视口装载。
公式按文档顺序处理，每批最多24个，或到达约12毫秒后让出主线程。
单个公式、MathJax扩展加载及浏览器布局可能超过此预算。
新译文和动态插入的公式共用调度器。正文重载会建立新的调度器。
公式依赖失败时保留原始公式或既有片段图片，并显示降级状态。

页面的打印快捷键和 `window.print()` 等待 `reviewMath.complete()`。
独立HTML导出同样等待，并校验所有公式已处理；导出继续保存原文，重新打开时再次排版。
浏览器原生菜单打印不能等待异步页面任务。提前使用该入口时，打印保留未完成公式原文并显示明确提示。
联网MathJax范围保持不变；打印前等待状态完成可取得排版结果。

macOS仅报告项目根目录变化时，监听器先核对相关文件元数据。
仅输出或缓存变化不会触发重建。普通相关文件通知仍立即递增事件代数。
根目录合并通知可能增加元数据核对成本；它不会读取正文或PDF内容。

```mermaid
flowchart LR
    A[完整正文DOM与原始公式] --> B[按文档顺序排版]
    B --> C[短批次后让出主线程]
    C --> B
    B --> D[全部完成或可见降级]
    D --> E[等待校验后打印或独立HTML导出]
    F[新译文与动态公式] --> B
```

## 常驻入口与升级

使用 `latex-review-local list` 查看论文和服务状态。使用 `latex-review-local open` 打开入口。
每个真实根目录和主 tex 身份最多拥有一个持续预览及一个差异报告服务。
旧报告缺少身份时，按诊断显式提供 `--entry` 和 `--root`。
升级前须手动停止旧版本服务。新入口不接管未知 PID。
迁移和生命周期说明见[持续预览](live-preview.md)。

```mermaid
flowchart LR
 A[已有报告] --> B[验证论文身份]
 B --> C[完整候选副本]
 C --> D[同论文差异槽位]
 D --> E[固定地址内显示报告]
```
