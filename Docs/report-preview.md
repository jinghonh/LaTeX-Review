# 报告预览

使用独立命令预览任意已生成的报告目录，无需重新生成报告：

```sh
latex-review-preview .latex-review/latest
```

也可以传入 `report.html`，或在生成报告时的工作目录中传入论文入口：

```sh
latex-review-preview .latex-review/latest/report.html
latex-review-preview neural_networks/main.tex
```

传入 `.tex` 时只打开已有报告，采用启动目录配置中的 `output`，未配置则使用 `.latex-review/latest`。`--config` 可以选择项目配置。若生成报告时使用了 `--output`，请直接传入对应的报告目录；预览不会重新生成报告。

更新安装项目后即可获得该入口。也可在已安装本项目的 Python 环境运行：

```sh
python -m latex_review.serve .latex-review/latest
```

命令校验目录内存在 `report.html`，仅监听 `127.0.0.1`，默认由系统分配空闲端口。标准输出第一行是实际报告地址，启动提示及访问日志写入标准错误。可用 `--port 端口` 指定端口；端口冲突或报告无效时返回 4，参数错误返回 2。服务以前台进程运行，Ctrl+C 或终止信号会释放监听端口并正常退出。

服务提供完整报告目录，保留图片和预览的相对路径；关闭目录列表并拒绝解析到报告目录外的符号链接。预览期间保持报告目录稳定，避免同时重新生成或移动目录。响应禁用缓存，以便重新加载后看到当前资源。服务不会改变报告文件或自动打开浏览器。

配置 `[translation]` 后，本机服务也提供按需翻译接口。所有项目自动读取用户全局翻译默认值，并叠加当前目录或 `--config` 指定的项目配置；项目字段和同名术语优先。页面点击才请求模型，结果独立缓存在报告目录同级；报告文件仍保留原文，可通过“导出含译文报告”保存中文阅读结果。密钥从环境变量读取。`--translation-cache-dir` 可指定独立翻译缓存；详见[变更内容翻译](translation.md)。

## 阅读与对照

报告默认展示完整新稿。宽屏时，对应段落右侧的页边卡片显示变更类型、编号和改动组数，随正文一起滚动；相邻卡片拥挤时向下排列。展开后优先逐组显示相邻的修改前后片段，仅保留少量上下文，删除词句使用删除线，新增词句使用高亮；公式和引用保留完整展示。同一句涉及多种类别时，主要对照只展示一次，补充明细保留在全文展开区。点击正文划线、页边卡片或删除位置的小标记，会定位并展开对应对照，同时高亮对应内容；每次只展开当前一张卡片。正文划线也可用键盘聚焦后按回车或空格激活。窄屏时卡片回到对应段落下方，保持相同操作；打印时也恢复为段落下方的对照。

“完整段落对照”和“中文译文”分别按需展开。正文的原文／双语切换不改变右栏译文区域的展开状态；正文中的中文变更句仍可点击定位对应改动组。

整段删除保留原位置附近的查看入口，无法可靠定位时显示位置提示。变更目录默认收起，打开后可按操作和类别筛选；上一处、下一处及键盘快捷键会定位并展开对应改动。点击被当前筛选隐藏的正文划线，会恢复全部变更，使对应卡片可见。

工具栏可切换双稿对照，并启用同步滚动。报告说明、诊断及可用的编译页面默认折叠，页面链接会自动展开目标区域。界面只维护当前阅读位置，不保存已审阅进度。

## 智能体验收

项目的 [LaTeX Review 技能](../.agents/skills/latex-review/SKILL.md) 默认要求启动预览、检查实际页面并清理进程。检查覆盖报告内容、截图中的排版及资源、筛选、折叠和页面内跳转；不存在的控件不计入检查。外部编辑器协议单独记录，HTTP 页面可用不代表外部协议可执行。

HTTP 服务正常与浏览器工具允许访问是两个独立条件。工具缺失或明确禁止访问本机地址时，继续核对机器数据，并报告渲染及交互验收未完成。不得把源码读取或普通 HTTP 请求成功当成浏览器验收成功，也不得规避工具的访问限制。MathJax 仍需联网；加载失败应记录页面的降级表现。

验收结束或中断后，停止本次启动的服务并确认退出；仅在用户明确要求时保留。交付报告文件路径和验收结果，已停止服务的临时地址不作为可用链接交付。
