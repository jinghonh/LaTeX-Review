# 参考文献与宏占位预览

## 参考文献

两侧分别读取各自项目的 `\bibliography{...}` 或 `\addbibresource{...}` 所引用的 `.bib` 文件。引用旁按键显示作者、题目、年份；缺少某个字段时仅该字段显示“缺失”。简单 BibTeX 条目支持花括号或引号括起的字段，以及数字年份。字符串宏、拼接表达式和复杂 BibTeX 语义不会求值。重复键保留首次解析的条目并报告诊断；缺键或手写 `\bibitem` 等无法提取结构化元数据的格式保留引用键与说明。文献解析失败不会阻止报告生成。

简单表格的单元格也会显示引用元数据和已配置的宏占位；无法可靠解析的表格保留原文并给出局部诊断。
引用命令的可选备注不作为文献元数据字段显示；报告保留原始 LaTeX，供核对备注及其位置。

文献条目内容变化、引用键不变时，报告可以在两侧展示不同元数据，但**不生成独立语义主变更**。本功能不提供参考文献条目差异引擎；正文引用键变化仍按原有引用明细审阅。

## 声明式宏占位

在 `.latex-review.toml` 中为简单宏声明参数数量和预览策略：

```toml
[macros.badge]
arguments = 1
strategy = "replace"
template = "【#1】"

[macros.keepSource]
arguments = 2
strategy = "raw"
```

`replace` 把 `#1` 至 `#4` 替换成对应的必需花括号参数，以纯文本安全显示；模板也可调用同一配置中的其他占位宏。`raw` 直接显示整个宏调用原文，不使用模板。宏名只接受字母和 `@`，参数数量为 0–4。未声明的参数、未知模板宏或错误类型在配置阶段报错，命令行返回 64 并写入配置诊断。调用参数不足、递归定义或展开超限时，预览显示原文并留下可定位诊断。单次展开最多 8 层、128 次调用、4096 字符；配置最多 64 个宏。

例如 `\badge{重点}` 显示为 `【重点】`。`\badge` 缺少参数时保留原文；`template = "\\loop{#1}"` 的自引用会触发递归诊断。模板不能调用 `\input`、执行 Python 或外部命令，也不会载入论文自己的宏定义。页面保留审阅节点的原始 LaTeX，并将占位展开位置标记为“近似”。**占位预览只辅助内容阅读，不代表真实编译的宏语义或最终版式。**
