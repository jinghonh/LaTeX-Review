## 内部工作清单与验收条件

### 原票据 #23：缓存解析结果并验证增量运行性能

未变化内容可复用，同时任何会影响结果的变化都正确使缓存失效。

#### 验收条件

- [ ] 缓存键考虑文件内容、配置、解析器及渲染器版本，并通过依赖图失效受影响节点。
- [ ] Git固定版本可复用；工作区章节、宏、图片或文献变化触发必要重算，不复用错误位置或资源。
- [ ] 缓存损坏、缺失与并发写入不产生伪成功结果；支持明确清理或绕过缓存。
- [ ] 输出缓存元信息，比较冷、热与单章节增量运行；结果语义一致，性能数据记录设备和样例。

#### 范围边界

原设计耗时区间只作为参考，不设置跨设备硬性门槛。


### 原票据 #31：识别图片路径不变时的内容修改

图路径未改但文件内容已替换时，审阅仍能发现资源变更。

#### 验收条件

- [ ] 分别读取两版本资源内容并计算指纹，同路径不同内容产生图资源变化明细。
- [ ] 同内容不同路径仍保留路径变化语义；资源缺失与内容改变明确区分。
- [ ] 多图共享资源时，各图可定位到对应变化，但图内明细不重复抬高主变更数。
- [ ] 更新报告、机器数据与缓存失效要求，并使用两提交同路径图片验证。

#### 范围边界

比较文件内容，不承诺图片像素或视觉相似度判断。


### 票内顺序与集成验收

- [ ] 先建立内容指纹和依赖失效机制，再验证同路径图片替换会更新差异与缓存；缓存命中不得掩盖图片变化。

[原始技术设计](https://github.com/jinghonh/LaTeX-Review/blob/a148d6cf96472d7936e618b19e7290acec9d30a2/Docs/latex-review-technical-design.md)及总览 #1 的确认范围。原票据链接用于追溯，不表示仍需独立调度。

## 内部工作清单与验收条件

### 原票据 #24：提供同步滚动、快捷导航与上下文折叠

长论文中可以按对应节点同步阅读，快速浏览变更附近内容。

#### 验收条件

- [ ] 同步滚动可开关，按节点对应关系及节点内位置对齐，不直接绑定全文滚动百分比。
- [ ] 新增、删除和不等长内容附近选择可解释的相邻锚点，避免双向滚动反馈抖动。
- [ ] 提供上一及下一变更快捷键；输入框内不抢占按键，焦点行为明确。
- [ ] 完整文档和上下文模式可切换，筛选、折叠与跳转协作；长文档及无对应节点样例通过。

#### 范围边界

沿用基础可访问性约定，不强制交付暗色主题。


### 原票据 #28：从报告定位到编辑器中的源文件

支持环境可打开对应源文件位置，其他环境仍显示可复制位置。

#### 验收条件

- [ ] 提供显式配置的编辑器链接模板，验证至少一种实际可用的 macOS 编辑器。
- [ ] 路径与参数编码正确，拒绝危险协议及命令注入。
- [ ] 工作区来源可打开当前文件；历史版本不得冒充当前文件的同名行，无法提供历史副本时退回展示位置。
- [ ] 浏览器不支持链接或用户拒绝时仍可复制路径和行号；声明各编辑器的验证状态。

#### 范围边界

不臆造 Codex 或其他编辑器未公开支持的链接协议。


### 原票据 #29：打包允许联网公式渲染的单文件报告

一个报告文件携带本地展示数据和图片，可独立搬运，公式仍可联网加载。

#### 验收条件

- [ ] 内嵌报告数据、样式、交互及本地图片，不留下对原项目目录的依赖。
- [ ] 明确标识公式渲染可能需要联网；断网时原始公式与诊断提示保持可读。
- [ ] 不可内嵌资源使用明确错误或经说明的内容占位，不能静默留下本地文件外链。
- [ ] 搬运单个文件到新目录后验证正文、双侧图像、跳转及筛选，报告产物体积并记录资源限制。

#### 范围边界

本功能不承诺完全离线，公式外链是已确认的例外。


### 集成验收

- [ ] 同步滚动、快捷导航、上下文折叠、源码跳转和单文件打包组合使用时，节点定位和降级提示保持一致。单文件报告仍允许联网加载公式依赖。

## 内部工作清单与验收条件

### 原票据 #25：识别表格单元格与行列结构变化

简单表格可定位单元格变化以及行列增删，复杂情况仍保留整体审阅。

#### 验收条件

- [ ] 行列结构一致时定位变化单元格，结构改变时对齐可确定的行列并识别新增及删除。
- [ ] 单元格内数学、引用及转义分隔符不被当作错误表格边界。
- [ ] 明确支持矩阵；跨行跨列、嵌套和复杂宏无法可靠对齐时整体回退并说明。
- [ ] 数据、表格高亮和统计共享主变更与明细，提供重复行及空单元格歧义样例。

#### 范围边界

不承诺任意表格宏或逐单元格数学语义树。


### 原票据 #26：识别节点移动与跨章节修改

高置信度的移动可与删除新增区分，并保留移动前后位置。

#### 验收条件

- [ ] 覆盖同章节移动、跨章节移动及移动后局部修改；匹配不得重复占用节点。
- [ ] 新增移动类别并遵守模式兼容规则，携带旧新章节、位置及必要修改明细。
- [ ] 筛选、统计、双侧跳转与移动一致；移动加修改按一个主变更呈现。
- [ ] 重复内容及低置信情形保守回退删除新增，提供可复现样例。

#### 范围边界

不以内容相近直接推定移动。


### 原票据 #30：提供更精细的公式结构差异

常见公式结构能提供比纯词元更清楚的变化摘要。

#### 验收条件

- [ ] 明确支持变量、上下标、分式、根式及常见运算结构的比较范围。
- [ ] 至少覆盖下标替换、参数变更与子表达式增删样例，结构摘要关联原公式主变更。
- [ ] 受支持结构与不支持宏混合时保守回退基础词元差异，不能改变或损坏旧新公式预览。
- [ ] 用等价空白及不支持环境样例验证不会伪造数学等价或错误匹配。

#### 范围边界

不承诺通用数学等价证明或任意 LaTeX 公式解析。


### 分项完成定义

- [ ] 表格对齐、节点移动与公式结构差异各自通过对应样例及报告集成验收；任一项完成不代表整票完成。

### 原票据 #33：显式编译双版本论文并保留产物

用户显式请求时可验证实际排版，默认审阅路径仍不触发编译。

#### 验收条件

- [ ] 通过明确选项启用 latexmk 编译，默认分别编译两个隔离副本，可选择仅修改后版本。
- [ ] 支持可配置且实际验证的 TeX 引擎，保留各侧日志、生成文档和编译状态；缺工具时给出可操作诊断。
- [ ] 禁用 shell escape，设置超时和受控输出；原工作区及 Git 状态不变。
- [ ] 编译失败不删除已有结构报告，返回降级状态并明确失败侧；基础来源读取失败仍遵守既有状态码。

#### 范围边界

不自动安装 TeX；复杂宏的沙箱增强由本主票中的沙箱渲染子项实现。


### 原票据 #34：关联页面视觉差异与结构变更

在两版编译文档之间查看页面变化，并尽可能回到结构审阅位置。

#### 验收条件

- [ ] 生成双侧页面预览和视觉差异，识别页数变化，页增删不会简单导致后续全错位。
- [ ] 关联结构变更与可确定页面，映射不确定时标注而非给出虚假精确位置。
- [ ] 支持页面与结构视图互相定位；视觉差异和主变更统计分开展示。
- [ ] 使用页插入、段落重排、公式变化及单侧编译失败样例验证，缺少双侧文档时明确不可比较。

#### 范围边界

视觉差异不证明内容语义发生变化，也不取代结构差异。


### 原票据 #35：在受限沙箱中渲染复杂宏与绘图

显式启用后，可为复杂绘图和宏生成受控预览，失败不会拖垮基础报告。

#### 验收条件

- [ ] 提供独立启用配置和可验证的 macOS 隔离机制，约束文件访问、网络、执行程序及输出目录。
- [ ] 限制时间、内存、进程和输出量；嵌入渲染结果前继续清理可执行内容。
- [ ] 危险命令、无限循环、越界读写和资源耗尽样例被阻止或终止，产生可定位诊断。
- [ ] 沙箱不可用时明确拒绝高级执行并保留源码回退，绝不静默在宿主无隔离运行。

#### 范围边界

不承诺任意宏都能运行；普通解析默认始终不执行外部指令。


### 票内顺序与完成定义

- [ ] 先完成受限的基础双版本编译，随后分别完成页面视觉联动及复杂宏沙箱；将原票间依赖作为票内顺序，不生成主票自依赖。
- [ ] 三个子项都通过验收才关闭本票并解除下游 #38 的阻塞；基础编译成功不能代表沙箱能力已完成。
- [ ] 保留默认不编译、显式启用、高级执行隔离及失败回退的原有边界，不因合票改成默认启用沙箱或复杂宏执行。

### 原票据 #38：提供不改变退出码的论文规则诊断

引用、标签、公式编号和图表引用问题可被定位，并区分既有与新增问题。

#### 验收条件

- [ ] 检查引用键无法解析、标签重复、公式编号变化及图表未被引用，说明各规则的支持边界。
- [ ] 正常删除引用不自动视为错误；重复标签列出各定义处，无法确定编号时给出未知。
- [ ] 通过双版本结果区分既有、新增和已解决问题，输出级别、证据及来源。
- [ ] 规则结果写入诊断并可在报告查看，但规则诊断本身不改变命令退出码；解析或编译降级仍按原协议处理。

#### 范围边界
