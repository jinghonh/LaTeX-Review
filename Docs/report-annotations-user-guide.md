# 报告批注操作

报告和持续预览使用同一套批注。作者标签表示来源，不是身份认证。

页面每 2 秒检查批注版本。代理添加或修改批注后，页面自动更新列表和正文标记。自动更新保留选中批注、筛选条件和未保存草稿。页面回到前台时会立即检查。

智能体添加、回复和管理批注的命令见[智能体接口](agent-tools.md#批注读取与修改)。

1. 在修改后正文中选择单个段落内的文字。点击选区旁的“批注”。
2. 点击公式节点，选择完整公式。MathJax 内部字符不提供独立坐标。
3. 填写修改意见并点击“保存”。“作者与分类”提供可选设置，页面记住作者名称。
4. 点击正文旁的数量标记。右侧面板显示该位置的批注。选择批注后，正文滚动到对应原文并保持高亮。
5. 点击“全部批注”查看总览。默认隐藏已解决批注；“筛选与排序”可切换状态。
6. 点击每条消息下方的“编辑”按钮修改消息。“删除批注”统一删除整条批注及其回复，删除前显示回复数量并确认。
7. 在“导入与导出”中管理备份。删除后没有界面恢复入口。

桌面端面板与正文并排显示，窄屏面板覆盖正文。关闭面板或按 Escape 会保留草稿。
作者名称与身份显示在首行，状态与分类显示为独立标签。展开后显示创建时间。
回复区域显示回复数量。回复按父消息 ID 嵌套，使用缩进和竖线显示层级。每条回复显示作者、身份、分类和时间。
点击回复下方的“回复”按钮，向该消息回复。旧回复没有父消息 ID 时，保留在第一层。系统不根据作者名或正文猜测层级。
列表保留内容摘要与回复数量，仅展开当前批注。顶部搜索和底部导航保持可见。
批注不重复显示原文。有批注的原文保留浅色标记。当前批注使用黄色高亮。
切换批注时，黄色高亮移至新原文；关闭面板时清除黄色高亮，保留浅色标记。

```mermaid
flowchart LR
 A[选择当前正文] --> B[填写批注]
 B --> C[保存线程]
 C --> D[数量标记与右侧面板]
 D --> E[回复或管理线程]
```

文字按纯文本保存。`$x+1$` 或 `\(x+1\)` 表示行内公式。
`$$x+1$$` 或 `\[x+1\]` 表示块级公式。公式渲染需要联网加载 MathJax。
批注公式渲染失败时保留输入原文。用户输入不会作为 HTML 执行。

## 换版和草稿

持续预览保存源码后自动刷新。页面保留正文、作者、身份、分类及操作对象。
草稿按项目及页面路径隔离。关闭编辑器也会保留草稿。
正文未变化且匹配唯一时，草稿恢复原选区。不能可信匹配时，草稿保留输入。
此时重新选择当前段落或完整公式，再保存草稿。旧版本偏移不会直接用于新版本。

本机持续预览会持久化新版本关联。唯一高可信修改显示“自动迁移”。
歧义或删除显示“待重新定位”。卡片提供“手动重新关联”，不高亮猜测位置。
点击该按钮，再选择当前正文。“关联记录”显示关联时间和方式。完整关联历史保留在导出的批注备份中。
打开历史报告只读取该版本关联，不会把最新关联迁回旧版本。

编辑对象被删除或修改时，页面保留输入并提示冲突。
“检查当前操作对象”重新读取对象。检查现有内容后可以继续编辑仍存在的对象。

## 保存和分享

本机服务保存到论文项目的 `.latex-review/annotations/<project_id>.json`。
同一项目、同一入口的报告和持续预览共享磁盘批注。

`file://` 和没有本机 API 的静态 HTTP 报告使用 IndexedDB。
同一浏览器来源内，同项目窗口通过事务保存，并通知其他窗口重新读取。
浏览器来源包含协议、主机及端口。不同来源、浏览器配置或设备不会自动同步。
清除浏览器数据会删除离线批注和草稿。请使用导出备份保存更新。

“导出批注 JSON”包含删除记录、正文版本和关联历史。
HTML 和 JSON 携带完整源码快照，包括所在正文单元的源码注释。
页面不会把这些快照自动显示为论文正文。
“导入批注 JSON”去重相同记录。同 ID 内容不同会拒绝整批导入并列出冲突。
原备份文件仍保留。页面不会根据更新时间静默覆盖冲突记录。
携带备份与浏览器记录冲突时，页面保留浏览器记录并提示冲突。
“导出报告原备份”可取出报告携带的原始记录。

“导出最新 HTML”携带最新批注、当前清单和本地图片。
导出会清除运行时卡片、选区标记及 MathJax 产物。新页面重新构建界面。
联网公式依赖仍保留。原有报告交付继续携带已有译文。

源码降级报告没有可靠正文清单，因此不能新建正文批注。
磁盘中的线程保留。结构预览恢复后可以重新定位。
分享报告不会创建不存在的本机论文目录。
离线匹配使用更保守的唯一完整原文规则；修改后的正文需要手动关联。

## 接受源码建议

1. 添加或回复批注时，展开源码建议，填写原始 LaTeX 和替换 LaTeX。
2. 打开消息中的建议，点击“预览源码差异”，核对文件和替换范围。
3. 点击“接受并应用源码建议”，显式回写源码。过期建议需要重新生成。
4. 检查更新后的报告与源码。应用成功不会自动解决批注；复核后再判断是否解决。

```mermaid
flowchart LR
 A[填写原始与替换 LaTeX] --> B[预览差异]
 B --> C[接受并应用]
 C --> D[检查报告和源码]
 D --> E[独立复核批注状态]
```

简单图注与单元格提供精确源码位置。复杂结构、跨文件区间及 Git 历史版本不能直接回写。
离线报告保存建议，但回写需要本机服务。生成器保存重建配方，固定旧版来源，并在新报告成功后切换页面。
旧报告缺少配方或重建失败时，显示“源码已修改、报告待更新”，保留旧报告和批注。
